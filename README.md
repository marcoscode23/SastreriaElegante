## 📌 Descripción del Proyecto

Este es el repositorio oficial de la página web de **[Nombre de tu Sastrería]**. Nos especializamos en la confección de trajes a medida para hombre, ofreciendo telas de alta calidad y un corte impecable para el hombre moderno.

El objetivo de este proyecto es mostrar nuestro catálogo de trajes, informar sobre nuestros servicios de ajuste a medida (sastrería) y facilitar el contacto con nuestros clientes.

> "La elegancia no consiste en llamar la atención, sino en ser recordardo." - *[Autor de la cita]* 

🌐 **Visitar la Página:** [Enlace a tu página web]

---

## ✅ Características

*   **Catálogo de Trajes:** Exhibición de modelos clásicos y modernos.
*   **Galería de Telas:** Muestra visual de los tejidos y colores disponibles.
*   **Información de Contacto:** Datos de ubicación, horarios y formulario de contacto.
*   **Diseño Responsivo:** Se adapta perfectamente a dispositivos móviles y escritorio.
*   **Código Optimizado:** Rápido y ligero para una buena experiencia de usuario.

---

## 🛠️ Tecnologías Usadas

Para el desarrollo de este sitio static, hemos utilizado las siguientes tecnologías:

*   **HTML5:** Estructura semántica del contenido.
*   **CSS3:** Estilos y diseño visual (Flexbox/Grid).
*   **JavaScript:** Interactividad básica del sitio.
*   **Font Awesome:** Para los iconos de redes sociales e interfaces.
*   **Google Fonts:** Tipografía elegante (ej. Playfair Display, Lato).
