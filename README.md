
🧵 Atelier Heritage | Sastrería de Alta Gama
StatusTech

Una experiencia digital premium diseñada para una sastrería artesanal, donde la tradición del oficio se encuentra con el diseño web moderno. Este proyecto recrea la sofisticación de la sastrería a medida a través de una interfaz minimalista, tipografía clásica y una arquitectura de componentes robusta.

✨ Características Principales
Diseño Responsivo: Adaptabilidad total desde dispositivos móviles hasta pantallas de escritorio.
Estética "Heritage": Uso de la tipografía Playfair Display para transmitir lujo y tradición.
Experiencia de Usuario: Navegación fluida y secciones optimizadas para la conversión (Citas, Catálogo, Proceso Artesanal).
Artesanía Digital: Cada sección ha sido construida respetando los principios de jerarquía visual y espacios en blanco.
🛠️ Stack Tecnológico
Este proyecto fue desarrollado utilizando estándares modernos para garantizar rendimiento y mantenibilidad:

HTML5 Semántico: Estructura clara y accesible para SEO.
CSS3 Avanzado:
CSS Grid: Utilizado para la disposición estructural de las secciones principales y galerías.
Flexbox: Implementado en sistemas de navegación, botones y alineación de componentes internos.
Variables CSS: Para una gestión coherente de la paleta de colores (#1a1a1a, #fdf8f8) y espaciados.
Vanilla JavaScript: Lógica para interactividad, menús desplegables y animaciones sutiles.
📐 Arquitectura de Diseño
El proyecto sigue un sistema de diseño estrictamente definido:

Colores: Una paleta monocromática sofisticada que resalta las texturas de las telas.
Tipografía: Playfair Display para títulos (elegancia) y fuentes sans-serif para legibilidad en cuerpo de texto.
Componentes: Footer dinámico, Navigation Drawer para móviles y Top App Bar consistente.
